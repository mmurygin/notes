# Low Level Design Interview

## Delivery Framework

### 1. Requirements
1. Primary capabilities
2. Rules and completion - what conditions define success, failure, or when the system stops or transitions state
3. Error handlings
4. Scope boundaries

### 2. Entities and Relationships

### 3. Class Design
For each enttity define state and behavior based on requirements.

### 4. Implementations
Start with happy path, then go into edge cases.

1. **Happy Path** - walk through method in a linear way, what the input, sequence of steps and finish on what it returns on how the state changes.
2. **Edge Cases**
    * invlid inputs
    * illegal operations
    * out-of-range values
    * calls that violate current system state


**Validate** your solution.
